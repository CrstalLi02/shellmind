You must run the ```./scripts/get_system_info.sh``` script to collect the current machine configuration, including username, operating system, CPU, memory, disk, and related info. Then run the ```./scripts/check_cleanable_files.sh``` script to list common junk files and cleanable content on macOS, including how much space they occupy.

After collecting the information above, address the current computer's username using the speech structure in reference.md and issue optimization-recommendation commands. For example, replace the name in "Xiaofuge, take this down" with the username you obtained, then write copy in the style of "I am making the following xxx deployment adjustments" so the user is given orders on how to optimize computer performance. The wording must stay consistent with the speech structure in reference.md, producing the experience of issuing commands.
